# JasmineR.Thomas.io

Professional website for **Jasmine R. Thomas** — ISO trainer, automation consultant, and CEO of OA AI.

## Overview

A sleek, minimal, black-white-grey website showcasing ISO 27001 & ISO 9001 training services, AI-powered automation solutions, and consulting offerings backed by 10+ years of experience.

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero tagline, solution cards, stats bar, CTA |
| Trainings | `trainings.html` | 7 specialized training programs with problem-solving excerpts |
| About Me | `about.html` | Professional bio, credentials & certifications |
| Get in Touch | `contact.html` | Contact form (name, email, phone, service, message) |

## Tech Stack

- **HTML5** — semantic markup with ARIA attributes
- **CSS3** — custom properties, grid, flexbox, responsive breakpoints
- **Google Fonts** — Inter
- **FormSubmit.co** — zero-backend contact form delivery

## Features

- Fully responsive (mobile, tablet, desktop)
- Accessible: skip-link, focus-visible outlines, reduced-motion support, ARIA labels
- Sticky navigation with mobile hamburger menu
- Consistent professional footer with page links and social icons (email, LinkedIn)
- Client-side form validation with honeypot spam protection
- Print-friendly styles
